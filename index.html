Why the under-prediction?

Q4 2025 deseasoned run rate was $5.0M/month. Q1 2026 deseasoned run rate was $6.9M/month — a +38% step-change in one quarter. No purely backward-looking model can forecast a regime shift before it happens. Key implication: the model now uses Q1 2026 as the base, so it starts from the correct current level. As long as no further step-change occurs, expected accuracy is ±10-13%.
